## C. What is incomplete (genuine gaps)
1. **V3 state ingestion.** WSS path decodes only V2 `Sync` (`wss_ingest.py:33` topic0, `live_base.py:decode_sync_log`). No V3 `Swap/Mint/Burn/Initialize` decoder, despite the Base universe being primarily UniV3.
2. **V3 initial state bootstrap.** No `slot0()` / `liquidity()` RPC read exists anywhere (grep: no `slot0`/`getPool`/CREATE2). A freshly-started process has empty V3 state until events arrive.
3. **sqrtPriceX96 → sqrt_p conversion.** Chain exposes `sqrtPriceX96` (Q64.96 integer, raw token1/token0). `amm_math.v3_amount_out` expects float `sqrt_p` and cache math is decimals-agnostic. No conversion util + no tests.
4. **Canonical pool registry with REAL addresses.** `base_venues.build_pool_graph()` emits synthetic ids (`uniswap_v3:USDC:WETH:500`) with `tvl_usd=0.0`. Real pool contract addresses are absent — required for WSS subscription + on-chain reads.
5. **TVL provider for V3.** `make_base_reserves_fn` uses V2 `getReserves()` selector `0x0902f1ac` (`live_base.py:128`) — wrong for UniV3 pools.
