## B. Production receiver architecture (Base mainnet)
Single-owner, two-flash-provider receiver holding NO standing balances; capital repaid before
the top-level flash returns.
- Balancer V2: entry `execute(address[],uint256[],bytes)` → callback `receiveFlashLoan(...)`, 0 bps.
- Aave V3: entry `executeAave(address,uint256,bytes)` → callback `executeOperation(...)`, 5 bps.
- Shared `userData = abi.encode(UniswapV3Adapter.SwapHop[] hops, address profitRecipient)`; each
  hop is a `SwapRouter02.exactInputSingle` leg with per-hop `amountOutMinimum` (slippage guard).
- Solidity 0.8.24, `via_ir=true`, `evm_version=paris`, optimizer runs 200, `bytecode_hash=none`
  (from `contracts/foundry.toml`).

## G. Security checks (static review)
- Authorization: `owner` immutable; `onlyOwner` on `execute`/`executeAave`/`rescue`. ✅
- Callback re-entry gate: `_authorized` + `_pendingProvider` (0/1/2) — callbacks revert
  `NotAuthorized()` outside an owner-initiated window and on provider mismatch. ✅
- Caller binding: `receiveFlashLoan` requires `msg.sender == balancerVault`; `executeOperation`
  requires `msg.sender == aavePool` AND `initiator == address(this)`. ✅
- Repayment: Balancer pushes `amount+fee`, reverts `InsufficientBalance` if short; Aave approves
  exact `owed` (pull model). ✅
- Slippage / min-output: per-hop `amountOutMinimum` enforced by `SwapRouter02`. ✅
- Arbitrary-call restriction: swaps fixed to `uniRouter.exactInputSingle`; **no** low-level
  `.call`/`delegatecall`; hop set is a typed struct. ✅
- Token handling: `TransferHelper.safeTransfer`; residual forwarded to `profitRecipient`. ✅
- Withdrawal control: `rescue(token,to,amount)` owner-only, post-mortem only. ✅
- No upgradeability / no delegatecall adapters / no governance timelock (documented v1 posture). ✅
Residual review items for an external audit before real capital: reentrancy across the two
providers (mitigated by `_pendingProvider`), `profitRecipient==0` handling (leftover retained on
executor, recoverable via `rescue`), and fee-on-transfer token exclusion (route allowlist upstream).
